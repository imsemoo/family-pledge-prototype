# Family Pledge — redesign prototype

Static prototype (HTML, CSS, JS, no build step) of a new identity and home page for familypledge.org.

- `index.html` — home page
- `game/qanadeel/` — the word-search game «قناديل الأقصى»
- `identity.html` — identity guide
- `assets/js/cast.js` — the character rig; `node tools/export-assets.cjs` writes standalone SVGs to `assets/illustrations`

Forms and calls to action link to the live site. Pages carry `noindex`.
